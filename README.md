# karavan-racing

> Venha nessa aventura nas estradas e tente alcançar a maior distância percorrida!!

------------------------------------------------------------------------

## 📜 **Descrição**

Um jogo baseado nos classicos de corrida das antigas.\
desvie dos carros que estão mais devagares que você e chegue cada vez mais longe...\
**"Um arcade rápido e dinâmico onde o objetivo é sobreviver o
máximo possível desviando de obstáculos e acumulando pontos."**

## 🎮 **Como Jogar**

### **🎛️ Controles**

-   **A / ←** -- mover para a esquerda\
-   **D / →** -- mover para a direita\
-   **S** -- desacelera\
-   **W** -- Acelera
